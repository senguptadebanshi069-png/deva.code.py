# Python ATM Simulation System

A fully functional, command-line Automated Teller Machine (ATM) simulation application built using **Python 3**. This project demonstrates core Object-Oriented Programming (OOP) concepts, robust error handling, and clean logical architecture.

## 🚀 Features
- **Secure PIN Authentication:** Implements a 3-attempt lock-out system to simulate modern security practices.
- **Account Balance Inquiry:** Displays real-time checking balance.
- **Cash Deposit & Withdrawal:** Validates inputs to ensure proper numeric entry and prevents account overdrafts.
- **Transaction History:** Generates a dynamic mini-statement tracking all operations within the current session.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Concepts:** Object-Oriented Programming (Classes & Methods), Control Flow (Loops & Conditionals), Exception & Input Validation.

## 🖥️ How to Run
1. Clone this repository or download the source code.
2. Open your terminal or VS Code in the project folder.
3. Run the following command:
   ```bash
   python deva.atm.py
   ```
4. Enter the default PIN `1234` to explore the ATM system!
